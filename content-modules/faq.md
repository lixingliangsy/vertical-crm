# TradeCRM — FAQ

**Q: Do I need to install anything?**
A: No. TradeCRM runs in your browser.

**Q: Is my input kept private?**
A: We use it only to generate your result and minimize retention. See Security.

**Q: Does it guarantee compliance / correctness?**
A: No. It is decision-support; you own the final call. See the honesty note in Security.

**Q: Can I export the result?**
A: Yes — JSON and CSV.

**Q: Is there an API?**
A: Yes, the web form is backed by a REST endpoint you can call from your pipeline.

**Q: What if I need a specific integration?**
A: Tell us; we add connectors users actually request.
