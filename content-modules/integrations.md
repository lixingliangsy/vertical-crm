# TradeCRM — Integrations

## Export
- Download results as **JSON** and **CSV** for any downstream tool.

## API & webhooks
- A REST endpoint backs the web form, so you can call TradeCRM from your own pipeline.
- Webhook-ready: fulfillment events are delivered via the Waffo Pancake webhook.

## Honesty note
We only claim connectors that exist today. If you need a specific integration (Zapier, Slack, Notion, Salesforce), tell us — we add the ones users actually request. We do not list 'available soon' connectors as if they shipped.
