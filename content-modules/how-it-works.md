# TradeCRM — How it works

1. **Input** — Describe or paste what you want analyzed (see the form on the home page).
2. **Run** — TradeCRM processes it with its rule set and returns a structured result.
3. **Act** — Review, copy as Markdown/text, and drop the output into your workflow.

In demo mode you get a realistic sample; the live run uses the same structure with your real data.
